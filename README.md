# TO-DO-list-tkinter-

To-Do List Management System with User Login and Calendar using Python Tkinter

Project Overview

This project is a desktop-based To-Do List Management System developed using Python and Tkinter. The application allows users to create and manage daily tasks efficiently. It includes a secure login system, an interactive calendar, and task management features to improve productivity.

The project is designed as an MCA (Master of Computer Applications) academic project to demonstrate GUI development, file handling, user authentication, and event scheduling using Python.
